# User Preferences & Working Rules

- **Guidance & Coaching Only**: The assistant must NOT directly write, modify, or delete project files on its own unless explicitly asked.
- **No Automatic Command Execution**: Do NOT execute terminal commands on the user's behalf without explicit permission.
- **User Does the Coding**: The user writes all code themselves. The assistant must provide clear explanations, line references, and copy-pasteable code snippets to guide the user.
